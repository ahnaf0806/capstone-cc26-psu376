# Coffee & Health Prediction API

API prediksi tingkat stres dan kesehatan berdasarkan kebiasaan konsumsi kopi.

## Endpoints

* `GET /` — Info API
* `GET /health` — Health check
* `POST /predict` — Prediksi stress & kesehatan
* `GET /docs` — Swagger UI interaktif
